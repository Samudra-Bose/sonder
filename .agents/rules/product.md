# Product & Domain Rules

- Entity Hierarchy: Community → Workspace → Task → Subtask (depth limit 1-2).
- Projections: List, Board, Calendar, Timeline project the single canonical task set.
- Identifiers: Community-unique task prefixes (e.g. `FE-12`).
- Canonical Truth: All features must trace directly to `Community-Work-Management-v1.5/` and the decision register.
- Scope Boundaries: Never introduce a `Project` entity or routes.
